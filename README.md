# Project Setup

This project uses [uv](https://github.com/astral-sh/uv) for Python package management and environment setup.

## Prerequisites

- Python 3.8 or higher installed
- [uv](https://github.com/astral-sh/uv) installed (`pip install uv`)

## Installation

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd <your-project-directory>
   ```

2. **Install dependencies:**
   ```bash
   uv pip install -r requirements.txt
   ```

3. **(Optional) Run the development server:**
   ```bash
   next dev --turbopack
   ```

## Usage

- Activate your environment if needed.
- Run your application or scripts as described in the project documentation.
